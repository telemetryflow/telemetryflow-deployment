# Terraform Module — EKS (Observability Cluster)

[![Terraform](https://img.shields.io/badge/Terraform-%E2%89%A5%201.9.8-7B42BC?logo=terraform&logoColor=white)](https://developer.hashicorp.com/terraform/downloads)
[![AWS Provider](https://img.shields.io/badge/AWS_Provider-%E2%89%A5%205.72-FF9900?logo=amazonaws&logoColor=white)](https://registry.terraform.io/providers/hashicorp/aws/latest)
[![EKS](https://img.shields.io/badge/EKS-1.35-326CE5?logo=kubernetes&logoColor=white)](https://docs.aws.amazon.com/eks/)

Reusable module that provisions the **TelemetryFlow observability EKS cluster**.

## What it provisions

| Layer          | Resources                                                                                                                                            |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cluster**    | `aws_eks_cluster` (1.35), OIDC provider, control-plane logs                                                                                          |
| **Node group** | `aws_eks_node_group` (default **3 × t3.large** workers)                                                                                              |
| **IAM**        | Cluster + node roles, EBS/EFS CSI Pod Identity roles + policies, cluster-autoscaler (OIDC), AWS Load Balancer Controller policy, Route53 cert policy |
| **Add-ons**    | kube-proxy, vpc-cni, coredns, snapshot-controller                                                                                                    |
| **CSI**        | eks-pod-identity-agent, aws-ebs-csi-driver, aws-efs-csi-driver (Pod Identity associations)                                                           |
| **Network**    | EKS security group (SSH, PG, Redis, OTLP, NATS, node-to-node, egress)                                                                                |
| **Storage**    | S3 bucket (private, versioned, TLS-only, public-access blocked)                                                                                      |

## Usage

See [`HOW-TO.md`](./HOW-TO.md) and the environment wiring at
`terraform/environment/telemetryflow/tfo-eks/`.

## Notes

- Reads VPC / subnet / SG outputs from the `tfo-ec2` core stack via
  `terraform_remote_state`.
- CSI drivers use **EKS Pod Identity** (not IRSA). The
  `eks-pod-identity-agent` add-on is installed before the CSI associations.
- Cluster-autoscaler uses an **OIDC web identity** role (IRSA).
