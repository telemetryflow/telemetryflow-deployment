# TelemetryFlow - TFO EKS (Observability Cluster Environment)

[![EKS](https://img.shields.io/badge/EKS-1.35-326CE5?logo=kubernetes&logoColor=white)](https://docs.aws.amazon.com/eks/)
[![Workers](https://img.shields.io/badge/Workers-3*t3.large-orange)](#)

Environment wiring that calls [`modules/eks`](../../modules/eks/) to deploy the
TelemetryFlow observability cluster. See [`HOW-TO.md`](./HOW-TO.md) for full
instructions.

Run order: **`_tfstate`** → **`tfo-ec2`** → **`tfo-eks`**.
